# studioopenframe.com

Site oficial da OpenFrame · Studio de Sistemas. HTML, CSS e JavaScript puros, sem build.

- `index.html` — página
- `styles.css` — estilos (fonte D-DIN, licença SIL OFL)
- `app.js` — animações: acoplamento do logo, entropia reversa, centro de controle, missões, piloto automático
- `assets/` — logo, vídeo do manifesto, fontes, ícones

## Contato do formulário
Em `app.js`, preencha `CONTACT.whatsapp` (só números, com código do país) ou `CONTACT.email`.

## Deploy
Vercel → Add New Project → importar este repositório → Framework: Other → Deploy.
Depois: Settings → Domains → `studioopenframe.com` e `www.studioopenframe.com`.
